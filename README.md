# Leve Pudim

Frontend Next.js conectado ao backend Django REST via API.

## Configuração

1. Copie `.env.example` para `.env.local`.
2. Configure `NEXT_PUBLIC_API_URL` com a URL da API Django.
3. Execute `npm install`.
4. Execute `npm run dev`.

Por padrão, o frontend usa `http://localhost:8000/api`.

## Scripts

- `npm run dev`: desenvolvimento
- `npm run build`: build de produção
- `npm run start`: servidor de produção
- `npm run lint`: lint
